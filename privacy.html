隐私政策

适用应用：DramaBridge Studio · 最后更新：2026 年 10 月 13 日

1. 适用范围与运营团队

本政策说明 DramaBridge Studio（剧桥工作室，以下简称“我们”）在提供 YouTube 频道授权、视频上传和发布管理功能时，如何访问、使用和保存相关信息。本政策也说明本公开介绍网站的托管情况。

运营团队：DramaBridge Studio（剧桥工作室）
联系邮箱：li5264a@gmail.com

2. 我们处理的信息

  • 频道信息：通过 YouTube API 取得的已授权频道 ID、名称和头像。
  • 授权凭证：Google 签发的访问令牌和刷新令牌，用于执行用户已授权的操作。
  • 发布内容：运营人员选择的视频和封面，以及填写的标题、描述、发布时间、隐私状态及是否面向儿童等设置。
  • 任务与操作信息：上传后的视频 ID、视频链接、上传和处理状态、错误信息，以及操作人员标识、操作时间和操作记录。

本工具不获取 Google 账号密码。当前频道发布授权不用于访问 Gmail 邮件、通讯录或 Google Drive 文件。

3. 数据用途与授权范围

本工具使用 YouTube API Services，当前申请的授权范围为 https://www.googleapis.com/auth/youtube.force-ssl。该范围可支持查询、上传、修改及删除相关 YouTube 资源；本工具的实际操作受后台功能及运营权限控制。

  • 识别并验证目标频道，展示频道资料和授权状态。
  • 上传视频、设置封面及视频元数据。
  • 查询上传、处理和发布结果，执行运营人员选择的公开、私密或定时发布操作。
  • 取消未完成任务；取消过程中可能删除该任务已上传的对应视频。
  • 在授权有效期间自动刷新访问凭证，以执行后台任务和授权状态检查。
  • 排查故障、记录操作并维护服务运行。

4. 数据传输与接收方

执行授权或频道操作时，必要的授权信息、视频、封面和发布设置会传输给 Google 或 YouTube。Google 对相关数据的处理适用 Google 隐私政策。

为提供本工具，数据还会由相应的托管、存储及运行基础设施处理。后台数据的访问面向获得相应运营权限或承担服务运行职责的人员和系统，并限于完成相关工作所需的范围。

公开发布的视频及其元数据会按照运营人员选择的隐私设置，由 YouTube 向相应受众展示。

我们对通过 Google API 取得的用户数据的使用和向其他应用的传输遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。此类数据不用于出售、广告定向或训练通用人工智能模型。

5. 数据存储、保护与保留

本工具加密保存频道刷新令牌，并通过登录和操作权限控制限制后台访问。频道授权凭证不会通过频道列表接口展示给前端用户。频道信息、任务信息及操作记录保存在本工具使用的存储系统中，用于频道管理、任务处理和故障排查。

绑定有效期间，刷新凭证用于维持已授权的服务访问。解除绑定后，本工具删除所保存的该频道刷新凭证。历史任务及操作记录不会随解绑自动删除；如需清理有关数据，可以按下述方式提出请求。依法需要保留的记录按适用要求处理。

6. 撤销授权与数据删除

您可以通过以下方式管理授权：

  1. 在后台“频道管理”中解除绑定，删除本系统保存的该频道刷新凭证。频道存在未结束任务时，需要先处理相关任务。
  2. 在 Google 账号的第三方连接管理页面撤销 Google 侧对本工具的授权。

本工具内解除绑定与 Google 侧撤销授权是两个独立操作。解除绑定不会自动删除历史发布记录，也不会删除已经发布到 YouTube 的视频。

如需申请删除本工具保存的频道信息、发布任务或其他相关数据，请发送邮件至 li5264a@gmail.com，说明目标频道及请求范围。我们将在核验请求后说明可删除的数据范围和处理安排。请勿在邮件中发送密码、访问令牌或刷新令牌。

7. 本公开网站

本公开网站是由 GitHub Pages 托管的静态说明网站，不包含登录表单、Google 授权流程或后台数据接口，也不设置分析或广告追踪脚本。

访问本网站时，GitHub 可能为提供托管服务和保障安全而记录 IP 地址等访问日志。详情参见 GitHub 隐私声明。本网站的托管与运营后台的数据存储属于不同服务。

8. 政策更新与联系

本工具的数据处理方式发生变化时，我们会更新本政策和最后更新日期。有关隐私、授权或数据删除的问题，请联系 li5264a@gmail.com。

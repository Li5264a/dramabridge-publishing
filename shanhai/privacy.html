隐私政策

Shanhai Myths Upload

本政策适用于山海神话簿的频道核验和视频上传工作流。工作流使用 YouTube API Services。请在授权和使用前阅读本政策。

访问哪些信息

  • 用 youtube.readonly 取得授权频道的 ID、名称和公开标识，核对目标频道，并查询本工具所上传视频的可见性和处理状态。
  • 用 youtube.upload 提交运营者选定的 MP4、标题、说明和可见性，并接收 YouTube 返回的视频 ID。
  • 处理 Google 签发的访问令牌及刷新令牌，用于在授权有效期间完成上述操作。

怎样使用和保存

工作流运行在 ChatGPT 的 Codex Cloud 任务中。刷新凭据通过任务级网络密钥配置，用于访问 Google 的 OAuth 端点。选择的成片和发布设置通过 HTTPS 发送给 YouTube。任务可保留频道核验结果、视频 ID 和处理状态，用于追踪同一笔上传并避免重复提交。

工作流仅在完成授权操作所需的范围内使用数据。保存的频道和视频状态记录在 30 天内从 YouTube 重新核验，或予以清理。通过 Google API 得到的数据按 Google API Services User Data Policy 使用，包括其中的 Limited Use 要求。

  • Google 隐私权政策
  • Google API Services User Data Policy

撤销授权和删除记录

您可以在 Google 账号的第三方连接管理页面撤销本工具的访问权限。通过这个页面撤销授权后，运营者会停止相关任务，移除已保存的凭据，并尽快清理基于该授权保存的 API 数据。这项清理将在撤销后的 30 个日历日内完成。

您也可以邮件申请删除工作流保存的数据。请提供频道名称和希望删除的范围，便于核对请求。我们将在核验请求后尽快处理，并在 7 个日历日内删除工作流中可删除的相关数据。YouTube 上的视频由频道运营者在 YouTube Studio 管理。

  • 在 Google 账号中管理或撤销授权
  • 联系运营者处理隐私问题和删除请求
